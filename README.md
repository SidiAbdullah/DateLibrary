# 📅 Date Utilities System (C++)

A lightweight C++ project for handling and manipulating dates from scratch — without using built-in date libraries.

---

## 🚀 Features

* Validate dates (including leap years)
* Add / subtract days, weeks, months, years
* Compare dates (before / after / equal)
* Calculate difference between dates
* Get current system date
* Print monthly & yearly calendars

---

## 🛠️ Example

```cpp
stDate date1 = readFullDate();
printDate(getDateBySubtractingDays(date1, 10));
```

---

## 🎯 Purpose

Built to understand how date systems work internally and improve problem-solving skills in C++.
